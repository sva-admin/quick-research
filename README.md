# quick-research

Fast single-pass research producing a structured TL;DR brief with summary, key features, pros and cons, pricing, and a bottom line.

An original skill by Silicon Valley Academy.

## What it does

- One pass, one topic, about five minutes: what it is, how it works, what it costs, and whether you should adopt it.
- A fixed brief structure (TL;DR, How It Works, Key Features, Requirements & Availability, Pros, Cons, Bottom Line, Sources) so every answer is comparable to the last one.
- Official sources first (company blogs, docs, papers) over aggregator rewrites, with dates on everything and conflicting claims shown rather than smoothed over.
- Capped at 500 words, and it saves to your notes directory when you keep one.

Use it for a new tool, a product launch, or an announcement you need to understand right now. Reach for a deep-research skill instead when the answer has to be decision-grade and fully cited.
